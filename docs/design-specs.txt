# NEXUS CRM: EXECUTIVE BOLD DESIGN SPECIFICATION

## 1. DESIGN VIBE: "EXECUTIVE BRUTALIST"
This design is inspired by high-end financial terminals and editorial Swiss typography. It moves away from the "soft/bubbly" SaaS look towards a precision-engineered, high-contrast, and technical aesthetic.

## 2. THEME PALETTE
- Background (Deep): #0a0a0a (Rich Black)
- Background (Surface): #141414 (Dark Gray)
- Accent (Primary): #3b82f6 (Bright Blue)
- Accent (Success): #34d399 (Emerald)
- Accent (Warning): #fb923c (Orange)
- Borders: rgba(255, 255, 255, 0.1) (Subtle White)
- Text (Main): #ffffff (Pure White)
- Text (Muted): rgba(255, 255, 255, 0.4) (Faded White)

## 3. TYPOGRAPHY SYSTEM
- Sans-Serif (Primary): "Inter", weight: 400, 700, 900.
- Monospace (Data): "JetBrains Mono", weight: 500.
- Massive Headings: 7xl (72px+), Font-Black (900), tracking-tighter.
- Labels/Captions: 10px, Uppercase, Tracking-widest (0.2em), Font-Bold.
- Table Headers: 10px, Uppercase, 30% Opacity.

## 4. COMPONENTS & STYLING
- Corners: 0px (Sharp Brutalist edges). No rounded corners on cards or buttons.
- Borders: 1px Solid. No shadows.
- Cards: bg-white/5 (Glassmorphism with extreme transparency).
- Buttons: High-contrast (White background with Black text).
- Data Visualization: Flat colors, vertical scaling bars, minimalist progress lines.

## 5. LAYOUT PATTERNS
- Modular Sidebar: Fixed width, high-contrast separation.
- Executive Header: Minimalist search bar (border-only), focus on navigation markers.
- Vertical Rhythm: Large gaps (p-10, space-y-12) to allow typography to breathe.
